# Loadline

Interview-style system design practice in a self-contained web app.

## Run locally

Open `index.html` in a modern browser. There is no build step or dependency install. Google Fonts are optional; system font fallbacks are included.

## Practice flow

Each of the 23 prompts guides you through clarifying requirements, estimating scale, drawing an architecture, testing load and failure scenarios, and debriefing tradeoffs. A 45-minute timer, stage progress, notes, designs, and submissions are saved in the browser using local storage.

The canvas models traffic, latency, capacity, and estimated monthly cost. It is an interview aid; API design, data modeling, consistency, and durability still need to be explained by the candidate.
